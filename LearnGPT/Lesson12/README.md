## 操作步骤

### 建立新的对话，使用 Code Interpreter 插件

+ GPT4
  - Code Interpreter ✅

### 建立代码生成的提示词

```
请给我写个Python语言的密码生成函数，密码需要至少包括一个大写字母，小写字母，数字和标准字符，密码长度为14位以上。
```

### 执行 GPT 生成的代码

```
执行一下上面的代码
```

*Again*

```
请再执行一次
```

### 使用注意

Code Interpreter 是在 OpenAI 的服务器端沙盒中运行，一些外围访问会收到限制，比如爬虫程序等。
