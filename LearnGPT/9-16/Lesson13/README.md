Code Interpreter - 数据分析也用它
===============================

## 知识点

* 使用 Code Interpreter 分析泰坦尼克号的幸存者

## 官网

https://www.kaggle.com/competitions/titanic/overview

## 实战演习/说明讲解

>画面演示

+ 准备数据集 titanic.csv
+ 提交数据集 Code Interpreter
+ 编写执行数据分析提示词

## 操作步骤

### 准备数据集 titanic.csv

+ PassengerId: 乘客编号
+ Survived: 是否幸存
+ Pclass: 舱位等级
+ Name: 姓名
+ Sex: 性别
+ Age: 年龄
+ SibSp: 兄弟姐妹/配偶数量（在船上）
+ Parch: 父母/孩子数量（在船上）
+ Ticket: 票号
+ Fare: 票价
+ Cabin: 客舱号
+ Embarked: 登船港口

### 提交数据集 Code Interpreter

将数据集提交给 GPT-4 的 Code Interpreter

### 编写执行数据分析提示词

```prompt
请帮我分析一下这个数据集
```

```prompt
请帮我分析一下幸存者的特征
```

```prompt
请按舱位等级我分析一下幸存者，并给我画出图表，图表中请用英文
```

```prompt
请按性别帮我分析一下幸存者比例
```

```prompt
请按年龄帮我分析一下幸存者比例
```

```prompt
请按照舱位等级、性别、年龄综合分析一下幸存者比例
```

Done.
