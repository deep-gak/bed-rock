## 官网

## 实战演习/说明讲解

+ GPT-4
+ GPT-3.5
+ DALL·E
  - 根据文本生成和编辑图片
+ Whisper
  - 将语音转换为文本
+ Embeddings
  - 将文本转换为数字向量
+ Moderation
  - 检测文本的安全性，包括仇恨、威胁、自残、性、未成年人、暴力等
+ 开源模型
  - Point-E
    - 生成3D模型
  - Whisper
    - 语音解析生成文本
  - Jukebox
    - 音乐生成模型(停止更新)
  - CLIP
    - 对比语言-图像预训练模型，可用于图片理解分析生成
